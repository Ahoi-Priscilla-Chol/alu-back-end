# api

Python scripts that use a REST API (https://jsonplaceholder.typicode.com) to gather employee TODO list data.

## Scripts
- `0-gather_data_from_an_API.py <employee_id>`: prints the employee's TODO list progress
- `1-export_to_CSV.py <employee_id>`: exports the employee's tasks to `<employee_id>.csv`
- `2-export_to_JSON.py <employee_id>`: exports the employee's tasks to `<employee_id>.json`
- `3-dictionary_of_list_of_dictionaries.py`: exports all employees' tasks to `todo_all_employees.json`
